# DN E-Books Store & LMS Portal

මෙය සිසුන් සඳහා ඊ-පොත් (e-Books), කෙටි සටහන් (Short Notes) සහ ආදර්ශ ප්‍රශ්න පත්‍ර (Model Papers) ලබා ගැනීමට සහ පරිපාලකවරුන්ට (Admins) ඒවා කළමනාකරණය කිරීමට සකස් කරන ලද සම්පූර්ණ LMS සහ Admin Portal පද්ධතියකි.

## 🛠️ තාක්ෂණයන් (Tech Stack)
- **Frontend:** HTML5, Tailwind CSS, JavaScript, PDF.js, Chart.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (MongoDB Atlas & Mongoose)
- **Deployment:** Vercel (Frontend) & Render / Railway (Backend)

## 📂 Project Structure
- `backend/` - Node.js සහ Express API මඟින් දත්ත හුවමාරුව සහ ඩේටාබේස් සම්බන්ධතා පාලනය කරයි.
- `frontend/` - සිසුන් සහ ඇඩ්මින්වරුන් භාවිතා කරන පරිශීලක අතුරුමුහුණත (UI) සකසා ඇත.
